## Lo más importante (NUEVO)

**1. El reto de prompt injection de Fernando Irarrázaval (vía Willison).** 2.000 personas, ~6.000 intentos de jailbreak contra un asistente de IA con secretos adentro, corriendo sobre Opus 4.6 con entrenamiento anti-injection. Nadie logró filtrar el secreto. Es la contracara optimista de la lethal trifecta: muestra que el hardening del modelo importa, pero no reemplaza el diseño de blast radius. Caso de estudio ideal para abrir L6 con datos reales en vez de teoría.

**2. "The Coming Loop" (Ronacher, 23-jun).** Ronacher analiza cómo los loops de trabajo manejados por máquina están reconfigurando el desarrollo: dónde brillan y dónde tienen límites serios para mantener calidad de código y comprensión humana. Es la continuación natural de su tesis del "mental disengagement" y conversa directo con el Ralph loop de Huntley. Lectura obligada para vos porque toca el eje pragmático vs frontier que el curso debe exponer (L11/L13).

**3. Claude Code Week 25 + 26: dos semanas de features nuevas.** Lo que mueve la aguja:
- **`claude mcp login` / `logout`** (W26) — OAuth de un MCP server desde la shell, sin sesión interactiva.
- **Shell mode que responde** (W26) — `! npm test` y Claude explica el output. Apagable con `respondToBashCommands: false`.
- **Background subagents piden permiso en la sesión principal** (W26) — antes auto-denegaban; ahora el diálogo muestra qué agente pregunta.
- **`Tool(param:value)` en deny/ask rules** (W25) — ej. `Agent(model:opus)`. Permisos más finos por parámetro.
- **Artifacts** (W25, beta Team/Enterprise) — convertís el output de una sesión en una página live y compartible en claude.ai.
- **Auto mode bloquea git destructivo** (W25) + **`sandbox.credentials`** (W26, bloquea lectura de secrets en sandbox).
