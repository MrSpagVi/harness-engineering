## TL;DR — qué hacer esta semana

- **Probá `claude agents`** (Agent view, Week 20 release) para ver todas tus sesiones en un solo panel. Útil sobre todo si ya estás corriendo background sessions con `claude --bg`. Una pasada de 5 min para entender qué muestra.
- **Instalá [Semble](https://github.com/MinishLab/semble) como MCP server** en un proyecto chico (ej: SpagBook). Usa embeddings + BM25 y promete 98% menos tokens que grep+read para code search. Si funciona, reemplaza una buena parte de las búsquedas que hace tu workflow.
- **Si tenés sub-agentes en tu proyecto**, agregales un **Agent-Scoped Hook** (PreToolUse/PostToolUse/Stop) en el frontmatter del agente — la feature ya está en Claude Code 2.1.x y permite hooks que solo corren durante la vida de ese sub-agente, sin contaminar el resto.

## Lo más importante (NUEVO)

**Antigravity 2.0 (Google I/O, 19 mayo)** — Google lanzó una plataforma agentic completa como competidor directo de Claude Code: standalone desktop app (no es VS Code extension), CLI, SDK, Managed Agents API, y enterprise tier. Modelo base: **Gemini 3.5 Flash** (4x más rápido que otros frontier, supera a Gemini 3.1 Pro en casi todos los benchmarks). Pricing: $25/mes Pro vs Claude Max $200/mes (8x más barato). Pero en SWE-bench, Claude Code mantiene ventaja en calidad (52.9% Pass@1 vs Flash speed-first). Importante: **Google deprecó Gemini CLI**, todo va a Antigravity CLI desde el 18 jun 2026.

**Claude Code Week 20 (v2.1.139-142, May 11-15)** — Tres features grandes: **`claude agents`** (Agent view) muestra todas tus sesiones (interactivas + background) en un solo panel con estado "running/blocked/done"; **`/goal`** mantiene Claude trabajando entre turns hasta que se cumple una condición de completion (útil para tareas largas que no querés babysittear); **Fast mode ahora corre Opus 4.7 por default** (antes 4.6; podés pinear el viejo con `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1`); **Rewind "Summarize up to here"** comprime contexto viejo en lugar de descartarlo.

**Semble — MCP code search 98% menos tokens (HN 442 puntos, 17 mayo)** — Combina static embeddings con BM25 retrieval para que un agente busque código sin comer tokens. Funciona como MCP server compatible con Claude Code, Cursor, etc. Zero config, no API keys, no deps externas. Es exactamente el patrón Ronacher de "Code over tools" / Ubertool aplicado a code search. Probable game-changer para proyectos grandes donde grep+read son lentos y caros.
